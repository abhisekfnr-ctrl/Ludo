Royal Ludo v25
==============
Admin / live control:
- Select/filter a room.
- See room status, active turn, dice, last dice and token state.
- Set next dice 1-6 for a specific player in a specific room.
- Random/clear forced dice.
- Open live board.
- Pause/resume/reset/close room.
- Kick player.
- Force active turn.
- Admin-only settings write endpoint.

Important:
The server remains a demo/early-production architecture using JSON file storage.
For serious public use, move state/auth to PostgreSQL/Redis and use Socket.IO/WebSockets.
